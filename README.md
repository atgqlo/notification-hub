Notification Hub 🚀

Notification Hub — это масштабируемый микросервис для асинхронной рассылки уведомлений, построенный на базе Java и Spring Boot.

Проект спроектирован с учетом энтерпрайз-практик: он изолирован в Docker-контейнерах, использует реляционную базу данных для надежного хранения статусов задач и покрыт модульными и интеграционными тестами. На данный момент реализована интеграция с SMTP-сервером Яндекса для отправки Email-сообщений.

🛠 Стек технологий

Core: Java 17, Spring Boot 3 (Data JPA, Web, Mail)

Database: PostgreSQL 15, Flyway (миграции БД)

Infrastructure: Docker, Docker Compose

Testing: JUnit 5, Mockito, Testcontainers (интеграционное тестирование с поднятием реальной БД)

Connection Pooling: HikariCP

✨ Ключевые особенности

Асинхронность: REST API мгновенно принимает задачу и сохраняет её в БД со статусом PENDING. Фоновый воркер (Background Worker) периодически забирает задачи и отправляет письма, не блокируя основной поток.

Надежность доставки: Использование БД гарантирует, что уведомления не потеряются при внезапном падении сервиса.

Контейнеризация: Приложение и база данных упакованы с помощью Multi-stage Dockerfile и связаны через docker-compose.yml.

Тестирование: Логика покрыта юнит-тестами (Mockito), а слой работы с данными проверяется через Testcontainers.

🚀 Быстрый старт (Запуск через Docker)

1. Требования

Убедитесь, что у вас установлены Docker и Docker Compose.

2. Настройка окружения

Создайте файл .env в корневой папке проекта и заполните его вашими данными. Пример:

DB_PORT=5435
DB_USER=mylogin
DB_PASSWORD=mypassword
DB_NAME=mydbname
MAIL_USERNAME=your_email@yandex.ru
MAIL_PASSWORD=your_app_password


(Для работы с Яндексом необходимо сгенерировать "Пароль приложения" в настройках безопасности почты).

3. Запуск

Откройте терминал в папке с проектом и выполните команду:

docker-compose up --build


Docker автоматически скачает нужные образы, инициализирует базу данных, накатит миграции Flyway и запустит Spring Boot приложение на порту 8080.

📖 Использование API

Создать новое уведомление

POST http://localhost:8080/api/notifications

Тело запроса (JSON):

{
  "recipient": "example@domain.com",
  "message": "Привет! Это тестовое сообщение из микросервиса.",
  "channel": "EMAIL"
}


Ответ (200 OK):
Возвращает объект созданного уведомления с присвоенным ID и статусом PENDING.
